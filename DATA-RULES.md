# Data rules

Every file in this repository follows these rules. They are the condition for the repository being public.

1. Every file here is synthetic. No employer, client or customer data, ever.
2. No real names, rates, account details, internal file names or system names.
3. Nothing here is deployed at, or endorsed by, any employer.
4. Each skill states its true supervised-run count. Runs not logged did not happen.
5. A human approves every output that leaves the workflow.
6. No bank name, department name or customer name appears anywhere, including commit history.

If you find a file that breaks a rule, open an issue. The file is removed, not argued.
